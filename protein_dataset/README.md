# protein_dataset

Artifacts for the protein subcellular-localization experiment in
[`../Protein.ipynb`](../Protein.ipynb). All files are written by the notebook and
read back by later sections of the same notebook, so relative paths matter: run
the notebook with the `machine-learning/` directory as the working directory.

## Contents

| File | Kind | Shape | Description |
| --- | --- | --- | --- |
| `uniprot_swissprot_go_cc.csv` | table | 9,895 x 3 | Raw UniProt export after removing entries without a GO CC annotation. Columns: `uniprot_id`, `sequence`, `go_cc_raw` (semicolon-separated GO terms in the form `term name [GO:xxxxxxx]`). |
| `go_cc_label_counts.csv` | table | 1,779 x 2 | Every distinct GO CC term found in the export with the number of proteins carrying it (`go_id`, `protein_count`). Sorted by decreasing count. |
| `selected_go_labels.csv` | table | 75 x 1 | The labels kept for modelling: all GO CC terms with `protein_count >= 100`, in the column order of the target matrix `go_labels.npy`. |
| `protein_ids.csv` | table | 9,895 x 1 | UniProt accessions in the row order of `esm2_embeddings.npy` and `go_labels.npy`. |
| `esm2_embeddings.npy` | array | 9,895 x 480 | `float32` mean-pooled ESM-2 (`esm2_t12_35M_UR50D`, layer 12) embeddings, one row per protein. |
| `go_labels.npy` | array | 9,895 x 75 | `float32` multi-label target matrix; entry `(i, j) = 1` when protein `i` is annotated with label `j` of `selected_go_labels.csv`. |

## Label statistics

- 1,779 distinct GO CC terms across 9,895 proteins.
- 75 terms pass the `protein_count >= 100` threshold.
- 36,188 positive label assignments, i.e. 3.66 labels per protein on average.
- 9,786 proteins (98.9%) carry at least one of the 75 selected labels; the
  remaining 109 proteins are all-zero rows in `go_labels.npy`.

## Regenerating

The files are produced in this order by the notebook:

1. `uniprot_swissprot_go_cc.csv` - section 2.1 (UniProt download + filtering, section 1.4).
2. `go_cc_label_counts.csv`, `selected_go_labels.csv` - sections 2.3 and 2.4.
3. `esm2_embeddings.npy`, `go_labels.npy`, `protein_ids.csv` - sections 3 and 4.4.

Re-running sections 1 and 4 overwrites the existing files; to rebuild only the
downstream analysis, keep the files and start at section 5.

## Consistency checks

Verified for the current snapshot:

- `protein_ids.csv` matches the `uniprot_id` column of `uniprot_swissprot_go_cc.csv` row by row.
- `go_labels.npy` is reproduced exactly by re-parsing `go_cc_raw` with the label
  order of `selected_go_labels.csv`.
- Row counts agree across the embedding matrix, the target matrix and the ID table (9,895).
- No missing values in the ID or sequence columns; no duplicate accessions.

`.ipynb_checkpoints/` is Jupyter autosave data and can be ignored (or deleted).
